Project Documentation

EduTrack

Student Registration and Academic Management System for Tutoring Centers

Role: Project Developer / System Designer

Project Type: Desktop application

Prepared: July 2026

Project Description

EduTrack is a desktop-based student registration and academic management system designed for tutoring centers, private educational offices, and small academic organizations. The system helps administrators manage students, academic levels, centers, groups, sessions, attendance, homework, quiz scores, reports, barcode IDs, payments, user accounts, and parent communication through WhatsApp.

The project focuses on making daily front-desk operations faster and more reliable. Instead of tracking student records manually, the system provides a structured workflow for registering students, assigning them to groups, scheduling sessions, scanning attendance, following homework and quiz performance, and keeping parents informed.

Project Objectives

  • Provide a simple and organized way to register and manage student information.
  • Support academic levels, centers, groups, sessions, attendance, homework, and quizzes.
  • Generate barcode IDs for faster attendance check-in.
  • Improve parent communication through WhatsApp notifications.
  • Give administrators reports and dashboard insights for better decision-making.
  • Store data locally so the system can operate as a practical desktop application.

Key Features

Student Management

Register, edit, filter, view, block, and organize students with contact details, barcodes, levels, centers, notes, and discount settings.

Academic Setup

Create academic levels and teaching centers, then use them across students, groups, sessions, and reports.

Groups and Sessions

Create groups with capacity, day, time, level, and center, then schedule sessions with fees, topics, homework, and quiz settings.

Attendance and Homework

Check students in by barcode or search, prevent duplicate attendance, track homework status, and export attendance records.

Quiz Scores

Record quiz scores for attended students, calculate percentages, add notes, and send quiz updates to parents.

Reports and Dashboard

View student, session, group, attendance, homework, quiz, discount, and revenue insights.

Core Workflow

  1. Create academic levels and teaching centers.
  2. Register students with contact details, parent phone numbers, and barcode IDs.
  3. Create groups and assign students to the correct group.
  4. Schedule sessions with date, time, topic, fee, homework, and quiz settings.
  5. Print barcode cards or stickers for students.
  6. Scan attendance during each session and update homework status.
  7. Enter quiz scores for attended students when a session includes a quiz.
  8. Review dashboard statistics and reports.
  9. Send attendance, homework, quiz, absence, and block notifications to parents through WhatsApp.
